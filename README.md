# Vixeqoote Sans

Repository scaffold for the supplied **Pixel Comic Sans (Undertale Sans Font)**.

## Source attribution

- Designer: **ColorSwitchFan25**
- Font: **Pixel Comic Sans (Undertale Sans Font)**
- Original source: https://fontstruct.com/fontstructions/show/1534860/pixel-comic-sans-undertale-sans-font

The FontStruct Non-Commercial Software End User License Agreement shown for this font states, among other restrictions, **no modification**, **no redistribution/making the font available to third parties**, and **no use as a webfont**.

For that reason this public repository intentionally does **not** contain the supplied TTF, converted font files, or derived individual SVG glyphs.

## Intended structure after written permission

If the font designer grants written permission covering conversion and public distribution, the repository can use:

```
font/
  source/
    vixeqoote-sans-font.ttf
  svg/
    U+0020-space.svg
    U+0021-exclam.svg
    ...
  glyphs.json
```

The SVG extraction can then preserve the original font-unit outlines and advance widths exactly, without redrawing the glyphs.
